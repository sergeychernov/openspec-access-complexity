# Локальный конфигуратор

```bash
node bin/openspec-assess.mjs configure            # свободный порт на 127.0.0.1
node bin/openspec-assess.mjs configure --port 4317
```

CLI печатает адрес (`http://127.0.0.1:<port>/configurator/index.html`). Остановка — `Ctrl+C` (SIGINT/SIGTERM закрывают сервер).

## Что можно делать

- **Матрица «параметр × модель»** с переключателем Apply/Verify. Колонка весов в обеих фазах коротко подписана «Вес» с кнопкой ⓘ, поэтому не расширяет таблицу; доступные имена полей сохраняют полное назначение («Вес параметра для реализации: logic» / «… для проверки: …»). Подсказка ⓘ открывается при наведении, при фокусе с клавиатуры и по нажатию (нажатие закрепляет её), закрывается по Escape или клику снаружи. Она выводится отдельной панелью поверх страницы (около 300 px, но не шире экрана), обычным шрифтом с переносами, вне обрезающей области прокрутки таблицы, и остаётся на экране в узком окне и при горизонтальной прокрутке. Текст: вес 2 даёт вдвое больший вклад, чем вес 1, при той же сложности; вес 0 исключает параметр из взвешенной оценки, но не отменяет обязательные ограничения; связь со сложностью профиля.
- **Ячейка модели** — «Оценка модели · 0–100» для модели, фазы, параметра и effort (полное доступное имя содержит всё это). Ввод до двух знаков (`82`, `82.01`); лишняя точность, значения вне 0–100 и непустой мусор отклоняются с сообщением, без округления. **Очистите поле, если данных нет**: пустой или пробельный ввод при завершении редактирования сохраняет явный unknown (буква `u`, placeholder «Нет данных»), прежняя запись и её источники остаются в `origin` и видны в карточке; `0` — это число. Отдельной кнопки или меню «Нет данных» нет; пояснение доступно в подсказке и `aria-description` поля. Так же работают ячейки ресурсов в «Все уровни».
- **Effort в заголовке модели** — селектор «Показать effort (только просмотр)»: можно одновременно смотреть Astra medium и Sol high; это не меняет config, его digest и рейтинги.
- **«Разрешены для рекомендаций»** — выпадающий multiselect с чекбоксами только для supported efforts модели. Свёрнутая кнопка перечисляет выбранные уровни через запятую в порядке supported efforts (при выборе всех — тоже все IDs, а не «Все»), её ширина ограничена, длинный список сокращается многоточием, полный текст — в подсказке и доступном имени. Меню остаётся открытым между переключениями, работает мышью и клавиатурой (Enter/пробел открывает, ↑/↓ — между уровнями, пробел — переключить, Escape — закрыть с возвратом фокуса), закрывается кликом снаружи. Снять последний уровень нельзя: галочка остаётся, появляется сообщение «Выберите хотя бы один effort» (полностью выключить модель можно флажком enabled). Изменение набора не переключает effort просмотра и не меняет записи качества и ресурсов; открытие и закрытие без изменений не меняют config.
- **«Все уровни»** — таблица параметр × supported effort выбранной модели в текущей фазе и строки ресурсов (множители токенов, нагрузки подписки и времени). Каждая ячейка — отдельная запись со своим индикатором происхождения.
- **Ресурсные множители** — в поле только число (`0.6`, `1.2`, `0.78`, без `×` и лишних нулей); подпись строки и доступное имя объясняют, что умножается («доля от минут категории, 1 = как в категории»). Разделитель — точка или запятая (`0,78` = `0.78`, сохраняется точно как 7800 bp и далее показывается с точкой), диапазон 0–100, до четырёх знаков после разделителя, без округления. Буквы, `×`, знаки `+`/`−`, экспонента и второй разделитель блокируются прямо при вводе; некорректная вставка (`1abc2`, `×1.2`) отклоняется целиком без изменения текста и значения, допустимая — вставляется (пробелы по краям отбрасываются). Навигация, выделение, удаление и последовательный набор дроби («1.» → «1.2») работают как обычно; итоговая проверка при уходе из поля остаётся обязательной. Очистка — «Нет данных» (`u`), `0` — число.
- **Индикаторы происхождения** — круги 18 px (область нажатия больше) со строчной буквой: p proxy, h heuristic, o user-override, u unknown, m measured; общая легенда над матрицей. Наведение и фокус клавиатурой показывают полное название и краткое основание; нажатие (или Enter/Space) открывает карточку: статус, значение, основание или объяснение пользователя, источники числа с mapping, подтверждающие свидетельства (явно помечены как не вычисляющие число), исходная запись, наследование, миграция и кнопка «Вернуть значение по умолчанию» для этой записи. Цвет только дополняет букву; в JSON сохраняются полные status IDs.
- **Модель**: `modelId` (ручная смена версии → записи помечаются `inheritedFrom`), enabled, доступность для аккаунта (отдельно от происхождения оценок), reset модели.
- **Политика выбора** (отдельно для API и подписки): «Время без штрафа g, мин», «Интервал начисления s, мин» (> 0), «Надбавка за интервал k, %» (до двух знаков; 0 % отключает учёт времени) с пояснением формулы. Это не важность параметров: она влияет только на сравнение расхода среди вариантов, прошедших порог качества. Для legacy-конфигураций показываются прежние веса и подсказка `switch-policy`.
- **Обязательные поля** (веса, параметры политики, пороги, наблюдения квоты) при пустом вводе дают ошибку валидации и не превращаются в 0 или unknown.
- **Preview**: для каждого кандидата — пригодность 0–100, C (верхний прогноз стоимости или нагрузки), T (типичное время), множитель штрафа и S «для сравнения (не цена)», плюс пояснение статуса и причин; Δ позиции относительно baseline. Выбор не зависит от округления отображения и от выбранного для просмотра effort.
- **API / Subscription / ограничения / Advanced JSON / import-export** — как раньше.
- **v1-файлы** отклоняются с подсказкой выполнить `migrate-config` ([migration.md](migration.md)).

## Проверено (раздел 11, браузерная панель Claude, 2026-11-14)

Мышью и клавиатурой: multiselect (несколько переключений без закрытия, Escape и клик снаружи, запрет снятия последнего уровня, неизменность config при открытии/закрытии, effort просмотра и записи модели не меняются); подсказка «Вес» при наведении, фокусе, нажатии и Escape, в окне 375 px после горизонтальной прокрутки панель целиком на экране; множители — посимвольная блокировка, запятая, диапазон, очистка и 0. Вставку из системного буфера эмулятор панели не доставляет, поэтому обработчик вставки проверен синтетическим событием `paste` с `DataTransfer` в реальном DOM (отказ целиком для `1abc2`, `×1.2`, `-1`, `1e2`, `1,2,3`; сохранение `" 0,6 "` как 0.6). Вставку и копирование через системный буфер в обычном браузере (допустимые `0,78` и `1.2` вставляются; `1abc2`, `×1.2`, `-1`, `1e2` отклоняются целиком) владелец проверил вручную. Отчёт preview совпадает с CLI-golden байт в байт.

## Безопасность и offline

Сервер (`src/node/server.mjs`) слушает только loopback, принимает только GET/HEAD, отвечает 421 на чужой `Host` (защита от DNS rebinding) и отдаёт файлы из allowlist (`configurator/`, `src/core/`, `config/`, `schemas/`, `examples/golden/`) с CSP `default-src 'none'; script-src 'self'; style-src 'self'; connect-src 'self'`. Нет CDN, внешних шрифтов, аналитики, login и вызовов моделей — страница работает без сети.

Assessment configurator

Edit the parameter × model matrix and resource settings. Preview uses the same evaluator as the CLI. Nothing is written to disk until you export.

Inputs

Parameter × model

Ячейки — «Оценка модели · 0–100» для выбранного в заголовке effort (просмотр не меняет расчёт). Пусто не бывает: отсутствие данных задаётся кнопкой «Нет данных». Уровень сложности параметра (0–4) берётся из профиля change и здесь не редактируется.

Происхождение: p proxy — оценка через косвенные данные с явным mapping h heuristic — эвристическая оценка o user-override — пользовательское значение u unknown — нет данных m measured — сопоставимое измерение

# Proposal

## Why

Users of the greeting tool want an emphatic variant for announcements.

## What Changes

- Add an optional `shout` option to `greet` that returns the greeting in upper case.
- Document the option in the README.

## Capabilities

### New Capabilities

- `greeting`: greeting text with an optional shout mode.

## Impact

One source file and its test. No stored data, no public network API.
